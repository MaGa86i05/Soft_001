# Soyuz MS 3D Model (Cinema 4D / Wavefront OBJ + PBR Textures) & PetroBPM Oil & Gas Business Process Suitability Suite (Python + Java + Windows EXE)

Комплексное инженерно-программное решение, объединяющее:
1. **3D-модель космического корабля «Союз МС» (`soyuz_spacecraft.obj` + `.mtl` + PBR UV-текстуры 2048×2048 + скрипт для Maxon Cinema 4D `c4d_soyuz_generator.py`)**, разработанную в точном соответствии с предоставленным референсом.
2. **Систему создания, моделирования и тестирования на пригодность бизнес-процессов нефтегазового производства (PetroBPM)** на базе **Python 3 + Java 21 OpenJDK** с **автоустановщиком Windows (`.EXE`)**.

---

## 1. 3D-модель Космического корабля «Союз МС» (Cinema 4D + Wavefront OBJ + PBR-текстуры)

### Архитектура 3D-модели и текстурных карт
- **Геометрия (`assets/model/soyuz_spacecraft.obj`)**: 6 113 вершин, 5 350 полигонов, 12 именованных конструктивных групп с полной UVW-развёрткой:
  - `BO_Orbital_Module_Hull` — сферический Бытовой отсек (БО) в мятой экранно-вакуумной теплоизоляции (ЭВТИ) тёмно-антрацитового цвета с шевроном **«СОЮЗ»**, триколором РФ, эмблемой **Роскосмоса** и круглой нашивкой миссии.
  - `Kurs_Docking_Assembly` и `Kurs_Radar_Antennas` — активный стыковочный агрегат «Курс» со штангой, приёмным конусом и параболическими антеннами сближения.
  - `SA_Descent_Module_Hull`, `SA_Dorsal_Harness_Fairing`, `VSK4_Optical_Periscope` — колоколообразный Спускаемый аппарат (СА) с бежевыми силовыми ремнями крепления, зелёным оптическим перископом космонавта ВСК-4 и иллюминаторами.
  - `PAO_Service_Module_Radiator`, `PAO_Propulsion_Bay_And_Nozzles` — белый радиаторный корпус Приборно-агрегатного отсека (ПАО) и двигательная установка КТДУ-80.
  - `Solar_Panel_Wings` и `Solar_Panel_Truss_Frames` — два четырёхсекционных крыла солнечных батарей с бежево-золотистыми кремниевыми фотоэлементами и ферменными штангами.
- **Текстурные карты PBR (`assets/textures/`)**:
  - `soyuz_diffuse.png` (2048×2048) — Albedo/Diffuse карта (складки ЭВТИ, логотип «СОЮЗ», флаг РФ, Роскосмос, ячейки солнечных батарей, белые радиаторы ПАО).
  - `soyuz_normal.png` (2048×2048) — карта нормалей рельефа складок теплоизоляции, заклёпок и ячеек солнечных батарей.
  - `soyuz_roughness.png` (2048×2048) — карта шероховатости/блеска материалов.
- **Скрипт генератора для Maxon Cinema 4D (`c4d_plugin/c4d_soyuz_generator.py`)**:
  - Нативный скрипт для Cinema 4D (R23–2025+), создающий иерархию объектов, деформатор складок `Displacer`, материалы с UVW-текстурированием и автоматическим экспортом в `.obj`.

## 2. Программа создания и тестирования на пригодность бизнес-процессов нефтегазового производства (Python + Java + EXE)

### Охваченные этапы производственной цепочки НГК
1. **Добыча нефти и газа (`EXTRACTION`)** — кусты скважин УЭЦН/фонтан, ГЗУ, контроль забойного/устьевого давления и обводнённости (ГОСТ Р 51858 / ПБ ОПО).
2. **Подготовка нефти и газа (`PREPARATION`)** — УПН, трёхфазная сепарация, электрообессоливание (ЭЛОУ), осушка попутного нефтяного газа.
3. **Переработка нефти и газа (`REFINING`)** — атмосферно-вакуумная трубчатка АВТ-6, каталитический крекинг, гидроочистка, ГПЗ (ТР ЕАЭС 036/2016).
4. **Транспортировка нефти и газа (`TRANSPORTATION`)** — магистральные нефтепроводы и газопроводы (МН/МГ), НПС/КС, узлы коммерческого учёта СИКН (СП 36.13330).
5. **Складирование (`STORAGE`)** — резервуарные парки РВСП-50000 с понтоном, ПХГ, установки улавливания лёгких фракций (УЛФ) (ГОСТ 31385).
6. **Утилизация нефтешлама (`SLUDGE_DISPOSAL`)** — шламонакопители, трёхфазные декантерные центрифуги (трикантеры), пиролиз/термодесорбция с возвратом углеводородов в цикл и биоремедиация кека IV класса опасности (ФЗ-89 / ИТС 15).

### Архитектура Python + Java + Windows Auto-Installer EXE
- **Java 21 Core (`java_engine/src/com/petrobpm/OilGasBpmEngine.java`)**: расчёт сквозного материального баланса, коэффициента технической готовности $K_\Gamma = \frac{\text{MTBF}}{\text{MTBF}+\text{MTTR}}$, термобарического запаса прочности ПАЗ и стохастическое моделирование методом Монте-Карло (1 000–5 000 итераций) с вынесением вердикта пригодности (`ПРИГОДЕН` / `УСЛОВНО ПРИГОДЕН` / `НЕПРИГОДЕН`).
- **Python 3.13 Orchestrator (`python_engine/bpm_orchestrator.py` & `server.py`)**: интеграционный мост Python↔Java, генератор схем **BPMN 2.0 XML** (`assets/petrobpm_workflow.bpmn.xml`) и веб-сервер интерактивной студии.
- **Автоустановщик Windows (`assets/downloads/PetroBPM_Soyuz3D_Setup.exe`, `installer/PetroBPM_Soyuz3D_Setup.iss`, `installer/Run_PetroBPM_Studio.bat`)**: самораспаковывающийся PE32+ `.exe` пакет и скрипты Inno Setup / NSIS с автопроверкой и установкой Python 3 и OpenJDK 21.
